# XY 博客写作

把文章写成一个具体的人在记录、解释和判断。作者是 XY，内容要有材料支撑，语气要自然，结构要服务于读者理解。这个 skill 适用于中文博客，也适用于需要保留 XY 个人口吻的英文博客；用户指定语言时跟随用户。

## 优先级

按以下顺序处理冲突：

1. 事实准确，不能把推测、想象或补写经历写成事实。
2. 保留用户本轮提供的观点、材料、链接、数字、引语、代码和格式。
3. 保持 XY 的叙述身份和明确立场，避免替 XY 增加没有依据的经历或情绪。
4. 让读者能顺着事实、动作、原因和结果读下去。
5. 最后再调整节奏、标题、段落和排版。

## 触发后先判断文章类型

- **个人经历或实践记录**：只写 XY 实际提供的经历、动作、选择、结果和反思。
- **事实型文章**：涉及人物、新闻、产品、数据、历史或用户案例时，先核验来源；能检索就先研究。
- **观点型文章**：把判断和依据放在相邻位置，明确判断的适用范围。
- **教程或评测**：写清前置条件、操作步骤、观察结果、限制和适用情况。
- **混合文章**：把必须准确的现实部分和可以抽象表达的观点分开处理。

如果是现实题材且材料不足，不能靠虚构案例、想象现场或重复解释补长篇。能查证的内容先研究；依赖 XY 私人经历或感受的内容，最多一次询问三个关键问题。无法补足时缩小题目或交付更短的文章。

## XY 的说话位置

- 介绍自己的项目、决定、实践和判断时使用“我”。“我”只能承担材料已经确认的事实。
- 讨论一般读者可能遇到的情况时使用“我们”或直接使用具体主语；不要用“大家都知道”“我们一定会”等无依据的群体判断。
- 只有在确实指导读者操作或用户原文使用第二人称时，才使用“你”。
- 对第三方产品或服务保持准确和克制。负面结果先写事实与条件；公开成稿要点名批评某个第三方时，先向用户确认。
- 第一次出现的专业名词、工具或 Skill，用一句自然的话说明它是什么以及为什么与本文相关。

## 文章推进

1. 开头尽快进入具体事情、问题、观察或判断，不预告全文结构，不套固定问候语。
2. 写作前在内部列出能托住文章的具体材料，优先包括动作、时间、数字、原话、失败、代价和后续结果。每个主要段落至少增加一个事实、区别、动作、例子或后果。
3. 一段集中处理一个关系。先让主语和动作出现，再补充原因、条件和例子。
4. 后一段承接前一段留下的问题。分类和小标题来自材料，不用“两个原因”“三层逻辑”代替内容。
5. 判断可以有个人倾向，但把依据放在附近，并说明边界。材料只支持“可能”时不要写成“必然”。
6. 写到事情已经讲清楚就结束，不强行升华、总结时代意义或添加行动口号。

## 语言和格式

- 使用平实、完整、适合朗读的现代中文。根据真实动作选择“整理、检查、修改、运行、完成”等准确动词，少用含义含糊的“搞、弄、做、用、看、查”。
- 删除空泛的机构腔、商业黑话、模型惯用语、讨好话、同义重复和没有来源的权威背书。
- 不用口号、新奇比喻、死物拟人或“烟头、深夜屏幕”一类未经材料支持的伪现场细节。
- 避免把读者并不存在的误解先立起来再推翻。直接下判断并给依据；不要使用“不是……而是……”“并非……而是……”“不在于……而在于……”“看似……实则……”等翻案句式。
- 不使用破折号。冒号只用于引出人物直接原话、网址、代码或机器字段，不能用作“核心是：”“总结：”式的提示。
- 不堆叠三项以上同构排比，不把动词名词化，不用“说白了”“先说结论”“值得注意的是”“综上所述”等模板化路标。
- 中文与英文、数字之间保留一个半角空格；中文句子用全角标点，英文和代码遵循原有格式。
- Markdown 标题直接说明内容。正文第一行不要重复 H1；保留用户已有的链接、代码、引用和层级。

## 标题和博客结构

标题只承诺材料确实支持的对象、动作、变化、结果或判断。标题中的“我”、时间、数量、结果和所有权表达都必须有证据。

常用结构可以从材料中自然长出来，例如：

- 一次实践的背景、过程、结果和复盘。
- 一个问题的具体案例、判断依据、限制和适用边界。
- 一项工具或方法的使用过程、对比观察和取舍。

不要为了显得完整而固定套用开场、三段论、金句结尾或首尾呼应。小标题是内容标签，不是宣传文案。

## 发布前检查

交稿前逐项检查：

- 每个现实事实、数字、引语和链接是否有明确来源。
- 是否把 XY 未提供的经历、用户反馈、心理和场景写成了事实。
- 每段是否真的推进了信息，是否重复了相邻段落的数字或结论。
- 长句的主语、指代和动作对象是否清楚。
- 标题是否超出了材料支持的范围。
- 是否残留翻案句、破折号、提示性冒号、黑话、空泛升华或聊天残留。
- 是否在事情讲完后及时停笔。

现实文章需要来源时，只在文末列出对结论重要的少数来源。个人经历和个人判断默认不附检索笔记。
