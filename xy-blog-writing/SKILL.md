# XY 博客写作

作者是 XY。文章要像她自己在讲刚做完的一件事：有材料、有判断、有坑，读起来像人在说话，不要写成说明文或公关稿。

中文默认。用户指定英文时跟随。口吻以 [references/voice.md](references/voice.md) 里的样本为准，不要套 oil-tone，也不要跑 oil 的检查脚本。写之前扫一眼 [references/edits.md](references/edits.md)，那里是 XY 实际改过的稿子。

## 优先级

1. 事实准确。没有依据的经历、情绪、用户反馈、现场细节，不要写成事实。
2. 保留用户给的观点、材料、链接、数字、引语、代码和格式。
3. 听起来是 XY，不是机构、不是老师念稿、不是另一个人的文风规范。
4. 读者能顺着事情读下去。
5. 最后再调节奏和标题。

## 口吻

先读 [references/voice.md](references/voice.md)。对得上那些段落，才算对。

- 讲自己的项目、决定、实践用“我”。没做过的事不要用“我”。
- 教别人、把东西递出去时可以用“你”，例如“你可以直接拿走”。不要用“大家都会”“我们都知道”。
- 像在复盘，不像在宣讲。可以有“于是”“所以”“其实”“当然”，但不要每句都加语气词。
- 单字动词能用就用：用、看、改、写、跑、搭。只有含糊的时候才换成更准的词，不要为了“书面”把“用”全部改成“使用”。
- 不要用比喻、俏皮话或拟物动词去包装技术行为。系统关闭了一个限制就写“关闭了”，不要写“把刹车拆了”；从安装包里取到文本就写“找到”，不要写“抠出来”。宁可平，不要巧。
- 破折号可以用来转一下、补一句，标题里也可以出现。不要为了禁标点把句子写僵。
- 引号只用 “” 或 ""，不要用「」。中文成稿默认 “”，英文或代码里的字符串用 ""。
- subagent、prompt、token 这类词可以直接用英文，不必强行统一成中文。
- “不是想讲 A，我想讲的是 B”这种纠正可以有，点到即可，不要整篇翻案。
- 重点可以用加粗。列表、编号、引用、代码块该出现就出现。
- 专业名词第一次出现时用一句人话说明它是什么、和这篇文章有什么关系。
- 括号里插一句自己的实际情况或自嘲是好的（“我就没有，我用的中转 API 哈哈”）。聊天残留指的是整段在寒暄、报进度、问读者，不是这种一句带过。

不要写成下面这样：

- 补虚词补到朗读发紧（“使用的时候”连着出现）
- 禁破折号、禁“你”、禁“用 / 看 / 改”
- 比喻、俏皮话、拟物动词（“旧刹车拆掉了”“把原文抠出来”）
- 机构腔、黑话、讨好、空泛升华
- 口号、金句结尾、“真正重要的是”
- 正文里出现「」
- 为了显得完整硬凑三段论或对称小标题

## 文章怎么往前走

- 开头尽快进具体事情。不要先问候，不要预告全文结构。先给一个“最近为什么在用这个东西”的由头（换了哪个版本、什么契机），比罗列自己做过哪些项目有用。
- 实践记录：只写她提供的动作、选择、结果、反思。
- 事实型：能查就先查。材料不够就写短，不要编案例补长度。
- 教程：写清前置、步骤、我踩过的坑、你拿走以后怎么用。
- 一段一件事。先把主语和动作写出来，再补原因和限制。但不要连着几段都是一句话——一句话的判断和它的点评用“所以”“然后”接在一起。
- 数字要写清它统计的范围：一次任务、一轮对话，还是一个会话的累计。“一个会话累计 93 个子智能体”和“一个五分钟的任务开了 93 个”是两回事，不要混。
- 有图或截图时，不要在正文里复述图里的内容，也不要解释这个工具怎么操作。一句话交代“我做了什么”就够，细节交给图。
- 判断可以有倾向，依据放在旁边。材料只支持“可能”就不要写成“必然”。
- 讲完就停。不要写“收尾”“总结”“结语”这类小节，不要回扣开头，也不要把前面的结论再复述一遍。工具怎么用、在哪打开这类操作信息，放在相关的那一段里，不要攒到最后。

## 标题

标题要能看出这篇文章在讲什么。对象、动作、结果必须有材料。优先写成读者会问的那个问题，后面可以接一句说明这是什么类型的经验，例如“为什么总感觉 Codex 很慢？从一个对话中开了 93 个子智能体得出的一些经验”。少用“我去翻了 XX”这类把自己的动作当钩子的写法。“干中学——agent的首token怎么优化？”这种破折号写法也可以用。

小标题是内容标签，不是文案。可以编号，也可以直接写“之前是怎么做的？”。

## 交稿前

- 有没有把她没说过的经历写成事实
- 读出来像不像 voice.md 里的人，而不像产品说明
- 数字、链接、引语还在不在
- 数字有没有写清统计范围（一次任务 / 一轮对话 / 一个会话）
- 有没有机构腔、空泛升华、以及「」
- 有没有多加一个“收尾/总结”小节，或者把结论又复述了一遍
- 最后一段是在讲事，还是在讲意义

个人经历和判断默认不附检索笔记。事实型文章只在文末留对结论重要的少数来源。
